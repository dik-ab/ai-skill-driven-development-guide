# ブラウザ検証手順

## 前提: 「テストが通った」と「画面で動く」は別

リファクタや繋ぎ込みの後は、ユニットテスト green でも画面確認までやって完了とする。
確認手順がこのファイルにあることで、環境再現に迷って止まることを防ぐ（手順を書かないと
AI は動作確認不十分のまま「完了」と報告しがち——実際にあった失敗の再発防止）。

## 手順

1. 開発サーバを起動する: `pnpm dev`（起動済みならポート確認だけ）。
2. Playwright でブラウザを操作し、変更した画面の主要フローを通す。
3. 各ステップでスクリーンショットを取得し、結果報告に添付する。
4. コンソールエラーとネットワークエラーも確認する。画面が「見えている」だけで
   済ませない。
5. 失敗した場合は、再現手順・スクショ・エラーログをセットで報告する。直せる場合も
   まず事実を報告してから直す。
