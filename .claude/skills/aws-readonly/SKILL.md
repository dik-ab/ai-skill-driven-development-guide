# AWS 読み取り調査手順

## 前提: 権限は IAM で物理的に絞ってある

すべての AWS CLI 実行に読み取り専用プロファイルを使う。**例外なし。**

```bash
AWS_PROFILE=ai-readonly aws logs tail /app/backend --since 30m
```

`ai-readonly` プロファイルには ReadOnlyAccess（またはより狭い ViewOnlyAccess）のみが
付与されている。つまり「AI が書き込みしないこと」はプロンプトではなく **IAM が保証**する。
このskillに書く手順は「守れ」ではなく「この範囲では自由に動いてよい」の宣言。

## 手順

1. 調査対象を特定する（サービス名・時間帯・症状）。
2. ログ → メトリクス → リソース状態の順で事実を集める。推測を挟まない。
3. 報告は「観測事実」と「そこからの推測」を明確に分けて書く。
4. 書き込み操作が必要だと判断したら、実行せず**コマンド案を提示して停止**する。
